# Shattered Pixel Deeper Darkness

This project is a modification of [Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/), expanding on the original game with new content, classes, and gameplay mechanics.

## About This Fork

Shattered Pixel Deeper Darkness builds upon the excellent foundation of Shattered Pixel Dungeon to create a deeper, more challenging dungeon-crawling experience. Key additions include:

- **New Hero Class: Artificer** - A crafting-focused class that uses a Pocket Workshop to create magical devices and tools
- **Extended Dungeon Depth** - Explore new areas beyond the traditional dungeon
- **Expanded Crafting System** - Create new items and tools with resources gathered during your adventure
- **New Enemies & Bosses** - Face additional challenges with new monster types and boss encounters
- **Additional Content** - More items, spells, and gameplay mechanics to discover

## Original Shattered Pixel Dungeon

[Shattered Pixel Dungeon](https://shatteredpixel.com/shatteredpd/) is an open-source traditional roguelike dungeon crawler with randomized levels and enemies, and hundreds of items to collect and use. It's based on the [source code of Pixel Dungeon](https://github.com/00-Evan/pixel-dungeon-gradle), by [Watabou](https://www.watabou.ru).

## Key Modifications

The main changes in this project focus on:
1. Adding the Artificer class and its associated mechanics
2. Extending the dungeon with new areas (the Purgatory levels)
3. Creating a more comprehensive crafting system
4. Adding new enemies, items, and gameplay features

All changes respect the original game's design philosophy while adding fresh content and challenges.
